# Mosaic Portfolio

Mosaic Portfolio پروژهٔ پایانی مشترک علیرضا عربشاهی و باران شیخ ستانی در بوت‌کمپ فرانت‌اند است. سایت اعضای تیم و پروژه‌هایشان را معرفی می‌کند و برای هر عضو یک صفحهٔ رزومه با آدرس قابل‌اشتراک و فایل PDF قابل‌دانلود دارد. صفحه‌های اعضا، پروژه‌ها و نوشته‌ها از داده‌ها و قالب‌های مشترک تیم استفاده می‌کنند.

سایت با Vite، React، TypeScript در حالت strict و TanStack Router ساخته شده و از فارسی و انگلیسی پشتیبانی می‌کند. جست‌وجو و فیلتر پروژه‌ها در URL ذخیره می‌شوند تا بتوان نتیجه را به اشتراک گذاشت.

## اجرای محلی

با Node.js نسخه‌ی 22.x به‌روز، از ریشه‌ی مخزن اجرا کنید:

```bash
npm ci
npm run dev
```

آدرسی را که Vite در ترمینال چاپ می‌کند باز کنید.

## مسیرهای سایت

| مسیر | محتوا |
| --- | --- |
| `/` | معرفی تیم، پروژه‌ها و نوشته‌های منتخب و راه تماس |
| `/team` و `/team/:slug` | فهرست اعضا و رزومه‌ی هر عضو با لینک دانلود PDF |
| `/projects` و `/projects/:slug` | فهرست پروژه‌ها با جست‌وجو و فیلتر در URL، و صفحه‌ی جزئیات هر پروژه |
| `/blog` و `/blog/:slug` | وبلاگ فعلاً چهار کارت «به‌زودی» دارد. هنوز مقاله‌ای منتشر نشده و محتوای مقاله‌ها بعداً اضافه می‌شود. |
| مسیرهای ناشناخته | صفحه‌ی «پیدا نشد» |

## بررسی‌ها

```bash
npm run lint
npx vitest run
npm run build
```

فایل‌های مسیر در `src/routes/` قرار دارند. بعد از افزودن یا تغییر مسیر، Vite فایل `src/routeTree.gen.ts` را تولید می‌کند. نسخه‌ی به‌روز این فایل را همراه تغییر مسیرها ثبت کنید.

## سایت زنده

لینک عمومی سایت پس از دیپلوی در PR انتشار اضافه می‌شود.
